# Abstract_Concrete
Work-friendly abstract images of (mostly) concrete structures, in the form of dual-monitor wallpapers, 3840x1080.

They are black and white, except for a handful of muted color photos. My goal was to make something that wasn't distracting in the background, but would still look good when all the windows were closed. Perfect for work focus.

All of these images started as freely available stock photos from sites such as Pexels, Vecteezy, etc. Edited with PhotoPaint, Photoshop or both. Please contact me if you have any questions or if there seems to be any kind of copyright infringement. As far as I can tell, these are all 100% authentic photos, no AI at all. I stored them in Github instead of Imgur so that I could keep the original file names, as a way of crediting the original photographers where I could.
