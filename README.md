# Abstract_Concrete
Abstract images of (mostly) concrete structures, in the form of dual-monitor wallpaper.

All of these images started as freely available stock photos from sites such as Pexels, Vecteezy and others. Some of them were used as-is and some I edited with either Corel PhotoPaint, Adobe Photoshop or both. Please contact me if you have any questions or if there seems to be any kind of copyright infringement.
