# Abstract_Concrete
Abstract images of (mostly) concrete structures, in the form of dual-monitor wallpapers, 3840x1080.

All of these images started as freely available stock photos from sites such as Pexels, Vecteezy, etc. Some were used as-is, but I edited most of them with PhotoPaint, Photoshop or both. Please contact me if you have any questions or if there seems to be any kind of copyright infringement.
